## 🚀 Featured Project

- [:fire: **Minecraft Web Client**](https://minecraft.aialec.cn) — a self-hosted, browser-native Minecraft client built on [zardoy/minecraft-web-client](https://github.com/zardoy/minecraft-web-client). I maintain a hardened fork with custom runtime patches: chunk-streaming fixes, meshing-worker offloading, entity interpolation/snap corrections, beacon-beam real-time sync, skin-library v2 (public presets + private per-player uploads), and low-latency UI event isolation.

## 🛠️ What I Do

- 🌐 **Self-hosting & infra** — nginx reverse proxy, multi-layer routing, CDN-edge + LAN hybrid caching, TLS termination
- 🎮 **Minecraft server ops** — Paper 1.20.4, custom Java plugins (BeaconResend, CityGuard, TNTGuard, MobGuard), AuthMe/LuckPerms hardening
- 🧩 **Browser runtime patching** — JS hot-patches on the web client for smoothness, animation correctness, and input isolation
- ⚡ **Performance tuning** — chunk streaming, web-worker meshing, entity animation & interpolation, latency hunting
